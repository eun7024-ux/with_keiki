# 위드케이키 ERP (회계 · 주문 · 재고 · 생산)

주문 접수부터 출고, 발주·입고, 재고, 생산(BOM), 거래명세서 출력, 매출·매입·비용과 순이익까지 한 곳에서 관리하는 사내용 프로그램입니다.
**B2B 주문 파일을 자동으로 받아 주문으로 접수**하고, 출고하면 매출과 재고에 바로 반영됩니다.
설치할 것은 **Python 3.9 이상** 하나뿐입니다. (엑셀 .xlsx 파일을 직접 올리려면 `pip install openpyxl` 추가)

## 실행

| 컴퓨터 | 방법 |
|---|---|
| Windows | `실행.bat` 더블클릭 |
| Mac | `실행.command` 더블클릭 |
| 직접 | `python3 server.py` → 브라우저에서 http://127.0.0.1:8700 |

사무실의 다른 PC에서도 쓰려면 비밀번호를 걸고 열어 주세요.

```
# Windows
set ACCOUNTING_PASSWORD=원하는비밀번호
python server.py --host 0.0.0.0
# Mac/Linux
ACCOUNTING_PASSWORD=원하는비밀번호 python3 server.py --host 0.0.0.0
```

장부 데이터는 `data/accounting.db` 파일 하나에 저장됩니다. 이 파일만 복사해 두면 백업이 됩니다. (설정 → 전체 백업으로도 받을 수 있습니다)

## 화면 구성

- **대시보드** – 오늘 할 일(출고 대기·납기 지난 주문·입고 예정·재고 부족), 기간별 매출·매출원가·**순이익**, 미수금, 예상 부가세, 월별 그래프
- **주문·출고** – 견적 → 주문 접수 → 출고 처리(택배사·송장번호). 출고하면 매출로 기록되고 재고가 빠집니다. 견적서·거래명세서 출력
- **발주·입고** – 자재·상품 발주 → 입고 처리. 입고하면 매입으로 기록되고 재고가 늘어납니다. 발주서 출력
- **재고** – 품목별 현재고, 출고 대기, 가용 재고, 입고 예정, 안전재고 대비 부족 표시, 재고 금액, 실사(수량 맞추기), 입출고 내역
- **생산** – BOM(완제품 1개에 들어가는 자재) 등록, 생산 등록 시 자재 자동 차감, 자재 부족 미리 확인, BOM 기준 원가 계산
- **매출 / 매입** – 수기 입력, 검색, 입금(지급) 처리, CSV 내보내기
- **비용** – 인건비·임차료·운반비 등 판관비
- **품목·단가** – 품목 구분(완제품·상품·자재), 판매단가/원가(마진 자동 계산), 안전재고, **거래처별 특별단가**
- **거래처** – 매출처/매입처, 거래처별 미수금, 기간별 거래내역서(정산서) 출력
- **자동 입력** – 파일 올리기, 폴더 자동 감시, API 연동
- **설정** – 회사명, 부가세율, 원가 계산 방식, 비용 계정, 문서에 찍히는 회사 정보(사업자번호·대표자·주소·계좌), 세무사용 CSV 내보내기

## 처음 시작할 때 (순서대로)

1. **설정**에서 회사 정보(사업자번호, 대표자, 주소, 연락처, 입금 계좌)를 입력합니다. 거래명세서·견적서·발주서에 그대로 찍힙니다.
2. **품목·단가**에서 품목을 등록합니다. 파는 것은 *완제품* 또는 *상품*, 만들 때 들어가는 재료는 *자재·부자재*로 고르고, 원가와 안전재고를 넣습니다.
3. 직접 만드는 제품이면 **생산**에서 BOM(1개당 들어가는 자재와 수량)을 등록합니다.
4. **재고**에서 품목마다 **[실사]**를 눌러 지금 창고에 있는 수량을 한 번 맞춥니다.
5. 이제부터는 주문을 받으면 **주문·출고**, 자재를 사면 **발주·입고**, 만들면 **생산**에 등록하면 됩니다. 재고와 매출·매입은 자동으로 따라옵니다.

## 업무 흐름

```
견적 ──▶ 주문 접수 ──▶ 출고 처리 ──▶ 매출 기록 + 재고 차감 ──▶ 입금 처리
발주 ──▶ 입고 처리 ──▶ 매입 기록 + 재고 증가
생산 등록 ──▶ 완제품 재고 증가 + BOM 자재 차감
```

- 출고/입고를 잘못 눌렀으면 목록에서 **[출고 취소]/[입고 취소]**를 누르면 매출·매입 기록과 재고가 함께 되돌아갑니다.
- 문서는 브라우저 새 창으로 열리고 **[인쇄 / PDF 저장]**으로 출력하거나 PDF로 저장해 거래처에 보낼 수 있습니다.
- 한 주문은 한 번에 전부 출고하는 방식입니다. 나눠서 보내야 하면 주문을 나눠서 등록하세요.

## 순이익 계산 방법

```
매출액(공급가) − 매출원가    = 매출총이익
매출총이익     − 비용(판관비) = 순이익(세전)
```

- 매출원가는 기본적으로 **판매수량 × 품목 원가**로 계산합니다. 품목·단가 화면에서 원가만 입력해 두면 이전·이후 매출 모두에 바로 반영됩니다.
  원가가 비어 있는 매출이 있으면 대시보드에 경고가 표시됩니다.
- 원가를 따로 관리하지 않는다면 설정에서 **"기간 내 매입 합계"** 방식으로 바꿀 수 있습니다.
- 모든 금액은 VAT 별도(공급가) 기준이며, 부가세는 `예상 부가세 = 매출세액 − 매입세액(매입 + 비용)`으로 따로 보여줍니다.
- 법인세·감가상각 등 결산 조정은 포함하지 않습니다. 최종 신고는 세무사 확인을 받으세요 (설정 → 내보내기 CSV 전달).

## B2B 주문 자동 입력 — 3가지 방법

B2B 파일은 **주문(출고 대기)** 으로 받는 것을 권장합니다. 같은 주문번호의 여러 줄은 한 주문으로 묶이고, 출고 처리하는 순간 매출이 됩니다.
이미 출고된 내역이라면 **매출**로 바로 넣을 수도 있습니다 (재고는 이때도 빠집니다).

### ① 파일 올리기
자동 입력 탭에서 B2B 사이트에서 받은 엑셀(.xlsx)·CSV 파일을 고르면 `주문번호/주문일/업체명/상품명/수량/단가/공급가액/부가세/결제금액` 같은 열을 **자동으로 알아봅니다**.
미리보기에서 열 연결을 확인·수정한 뒤 가져오기를 누르면 끝입니다. 맨 위 제목 줄, 맨 아래 합계 줄은 자동으로 건너뜁니다.

### ② 폴더에 넣기 (매일 자동)
`inbox/주문/` 폴더(바로 매출로 넣을 파일은 `inbox/매출/`, 매입은 `inbox/매입/`)에 파일을 넣어 두면 **1분마다 자동으로 읽어 장부에 넣고** `done/` 폴더로 옮깁니다. 읽지 못한 파일은 `error/`로 옮기고 가져오기 기록에 이유를 남깁니다.
브라우저 다운로드 위치를 이 폴더로 지정하거나, B2B 사이트의 자동 메일 첨부를 이 폴더로 저장하도록 해 두면 매일 손댈 일이 없습니다.

### ③ API 연동 (실시간)
쇼핑몰·ERP·B2B 플랫폼이 웹훅을 지원하면 주문이 생길 때마다 보내도록 설정할 수 있습니다. API 키는 설정 화면에 있습니다.

```bash
curl -X POST http://127.0.0.1:8700/api/ingest \
  -H "X-API-Key: (설정 화면의 키)" -H "Content-Type: application/json" \
  -d '{"kind":"order","rows":[{"date":"2026-10-25","client":"OO상사","item":"딸깍키트","qty":10,"order_no":"B2B-0001"}]}'
```

### 자동 입력 규칙 (세 방법 공통)
- **중복 방지**: 같은 주문번호+품목은 다시 들어와도 한 번만 등록됩니다. (주문번호가 없으면 일자·거래처·품목·수량·금액으로 판단)
  그래서 누적 파일을 매일 통째로 넣어도 새 주문만 추가됩니다.
- **단가 자동 적용**: 금액이 비어 있으면 `거래처별 특별단가 → 품목 기본단가` 순서로 계산합니다.
- **부가세**: 공급가만 있으면 10% 자동 계산, 합계만 있으면 공급가와 부가세로 나눕니다.
- 처음 보는 거래처·품목은 자동 등록됩니다. (품목 원가는 나중에 채워 주세요)
- 일자 열이 없는 파일은 파일명의 날짜(예: `매출_20261024.csv`), 그것도 없으면 오늘 날짜로 기록합니다.
- CSV는 UTF-8과 엑셀 기본 한글 인코딩(CP949) 모두 읽습니다. 구형 `.xls`는 `.xlsx`나 CSV로 다시 저장해 주세요.

예시 파일: `sample/b2b_매출_20261024.csv`

## 개발

```
python3 -m unittest test_server test_erp   # accounting 폴더에서 실행
```

- `server.py` – 서버, DB(SQLite), 가져오기·폴더 감시, 회계 보고서 (Python 표준 라이브러리만 사용)
- `erp.py` – 주문·발주, 재고, 생산(BOM), 문서 출력
- `static/` – 화면 (HTML/CSS/JS, 빌드 과정 없음)

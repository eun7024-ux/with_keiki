재고 = 매입·입고 수량 − 매출·출고 수량 ± 생산 · 실사 조정. 처음 쓰실 때 품목마다 [실사]로 지금 창고에 있는 수량을 한 번 맞춰 주세요. 출고 대기는 아직 출고하지 않은 주문 수량이고, 가용 = 현재고 − 출고 대기입니다.

BOM (완제품 1개에 들어가는 자재)

생산 등록

등록하면 완제품 재고가 늘고, BOM에 적힌 자재가 수량만큼 자동으로 빠집니다.

생산 내역 선택한 기간

매출 입력

단가를 비워두면 거래처별 단가 → 품목 기본단가 순으로 자동 적용됩니다. 처음 입력하는 품목·거래처는 자동 등록됩니다.

비용(판관비) 입력

품목 / 단가표

금액은 모두 VAT 별도(공급가) 기준입니다. 원가를 넣어두면 매출이 들어올 때마다 품목별 마진과 순이익이 자동 계산됩니다.

거래처별 특별단가

거래처

① 파일 올리기 (B2B 주문/매출 엑셀·CSV)

② 폴더에 넣으면 자동 입력

B2B 사이트에서 매일 받는 파일을 아래 폴더에 저장(또는 다운로드 위치로 지정)하면, 1분마다 자동으로 읽어서 장부에 넣고 done 폴더로 옮깁니다. 같은 파일을 두 번 넣어도 주문번호 기준으로 중복 등록되지 않습니다.
